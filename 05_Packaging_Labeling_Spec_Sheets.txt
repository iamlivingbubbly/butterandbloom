COLD-PROCESS SOAP — PACKAGING SPEC
===============================================================================

Bar Size: 3–4 oz (85–113 g) standard cut

Primary Packaging Options:
| Option | Material | Source | Specs |
|--------|----------|--------|-------|
| Kraft paper wrap | Recycled kraft paper | Uline Canada | 3.5" x 5" or 4" x 6" |
| Cling wrap | BPA-free cling wrap | Uline Canada | Food-safe, clear |
| Shrink wrap | Shrink film bands | Uline Canada | 3.5" bands |
| Muslin bag | Natural muslin | ClearBags Canada | 4" x 6" drawstring |
| Kraft pillow box | Recycled kraft | ClearBags Canada | 3.5" x 5" x 1.5" |

Primary Label:
| Element | Content | Size |
|---------|---------|------|
| Product Name | (e.g., "Lavender Oat Milk Bar") | 2" x 3" |
| Brand Name | "Butter & Bloom" | Top of label |
| Batch Code | (e.g., CP-20260807-01) | Bottom of label |
| Net Weight | 3.5 oz / 100 g | Bottom right |
| Made By | "Handcrafted in [City], AB" | Bottom |
| Barcode | Optional (UPC or SKU) | Right side |

Secondary Label (back or insert):
| Element | Required | Notes |
|---------|----------|-------|
| Full ingredient list (INCI) | Yes | In descending order |
| "Free from" claims | If applicable | Paraben-free, SLS-free, etc. |
| Directions for use | Yes | "Lather with water, rinse" |
| Warnings | Yes | "For external use only. Avoid eyes." |
| Expiry / Best By date | Yes | Mfg date + 2 years |
| Storage instructions | Recommended | "Store in cool, dry place" |
| Contact information | Yes | Brand name, email or website |

Label Material:
- Water-resistant paper or matte vinyl recommended (soap gets wet)
- Ink: black or dark print on kraft/white

Shelf Life: 1–2 years (CP soap)
Expiry Date: Manufacture Date + 24 months

BARCODE / UPC INFORMATION
===============================================================================

If selling on Amazon, in retail, or at markets requiring UPC:
- Obtain GS1 Canada UPC barcode: gs1ca.org
- One barcode per SKU (not per batch)
- UPC is 12 digits
- Print on label or apply as sticker

Internal SKU Format:
[Product Code]-[Scent Code]-[Size]
Example: CP-LAV-3OZ, BB-ROSE-3IN, SC-VAN-8OZ

PRINTING SPECIFICATIONS
===============================================================================

| Element | Spec |
|---------|------|
| Label paper | Matte or semi-gloss, water-resistant |
| Ink | Laser preferred (smudge-resistant); inkjet OK for short run |
| Font size (body) | 8–10 pt minimum for readability |
| Font size (brand) | 16–24 pt |
| Barcode size | Minimum 80% magnification, quiet zone maintained |
| Color | Full color or 1-color (black on kraft) |
| Finish | Matte, gloss, or lamination for water resistance |
